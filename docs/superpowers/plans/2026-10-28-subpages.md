# 下層ページ 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 特殊シミ抜き・高級ダウン/コート・料金・施工事例（一覧・詳細）・職人/運営会社・ご利用の流れ/FAQ・規約系の下層ページを、仮データと仮の画像枠で DESIGN.md どおりに表示する。

**Architecture:** 既存の `spc-theme`（見た目）と `spc-core`（データ・公開前チェック）の分担はそのまま。LPで作った部品（診断票・料金表・流れ・注意・FAQ）を `template-parts/sections/` に移して引数で使い回し、下層ページはスラッグ別のテンプレート（`page-{slug}.php`）で組む。説明文はテーマに固定し、依頼元が更新するのはCPTのデータ、規約・会社概要の本文、「お知らせ・補足」欄だけ（sitemap.md 決定事項11）。

**Tech Stack:** WordPress 7.1.3 / PHP 8.3 / `@wordpress/env` / PHPUnit（`npm run test:php`）/ Playwright（`npm run test:e2e`）

**Spec:** [DESIGN.md](../../../DESIGN.md) v1.3（特に §4「下層ページ」）、[docs/sitemap.md](../../sitemap.md) v1.3、[CLAUDE.md](../../../CLAUDE.md)。前回の計画 [2026-10-26-wordpress-theme-lp.md](2026-10-26-wordpress-theme-lp.md) の Global Constraints はすべて引き継ぐ。

## Global Constraints

- 前回計画の Global Constraints（CTA文言・`spc_line_url()`・接頭辞・フォームなし・色と書体・アクセシビリティ・エスケープ・NG表現・`TODO(仮)`）をすべて守る。
- CTAはヘッダー・ページ下部の相談ブロック（`spc_cta_block()`）・スマホ固定CTA・QRモーダルだけ。**ページの途中にCTAを置かない。** `cta_location` の値は増やさない。
- h1はページに1つ（下層ページは `--text-h2` の大きさ）。見出しの階層を飛ばさない。
- 墨地のセクションは1ページに1か所まで（下層では `/about/` の職人の欄だけ）。
- 色は白と灰白を交互に。各ページの並びと地は DESIGN.md §4「下層ページ」の表のとおり。
- テーマに書く未確定の文章には、コメント `// TODO(仮): 文言は依頼元確認後に確定 [copy:キー]` を付け、そのキーを `spc_theme_placeholder_copy()` に登録する（Task 3）。キーは `ページ.部分`（例：`stain.examples`）。
- テーマに置く写真の枠は、`spc_theme_placeholder_images()` に登録してから `spc_image_or_placeholder( spc_theme_image_id( キー ), … )` で出す。比率は DESIGN.md §5 に従う。
- 仮の文章は DESIGN.md §8（丁寧語・感嘆符なし・NG表現なし・分からないことは分からないと書く）に従う。具体的な技術・設備・実績の数字は書かない（依頼元に未確認のため）。
- `<body>` には必ず `data-page-type` を付ける。値は lp / service / price / case / about / guide / legal / other。
- e2e で設定・投稿を変えたテストは、最後に必ず元に戻す（`try/finally`）。WP-CLI 1回に約7秒かかるため、呼び出しはまとめる（`wp post generate` など）。

## Review Focus

1. **本番で仮データがすべて除外され、データが0件になった場合**：見出しだけのセクションが残らない。事例一覧は「準備中」の案内とCTAを出し、`noindex` にする → Task 4・6・7 のテスト
2. **長い値（料金の注記・会社概要や特商法の値・事例の素材）が入った場合（幅375px）**：表や診断票が折り返され、横スクロールが出ない → Task 10・11 のテスト
3. **依頼元が固定ページのスラッグを変えた・削除した場合**：専用テンプレートが外れたことを公開前チェックで検出する → Task 1 のテスト
4. **FAQの分類が未選択の場合**：ご利用の流れ・FAQページで「その他」の下に表示され、どこにも出ないことがない → Task 9 のテスト
5. **「お知らせ・補足」が空・空白だけ・`<p>&nbsp;</p>` の場合**：見出しごと出さない。HTMLを含む場合は `the_content` を通して表示する → Task 3・4 のテスト
