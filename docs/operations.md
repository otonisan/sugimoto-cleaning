# 運用手順書

高級染み抜き・全国宅配クリーニングのサイト（WordPress：テーマ `spc-theme` ＋ mu-plugin `spc-core`）の運用手順です。

- **Part A（開発・保守担当向け）**：環境構築、テスト、本番設定、公開前の手順
- **Part B（依頼元向け）**：管理画面でのサイトの更新方法

# Part A　開発・保守担当向け

## A-1. 前提ソフト

| ソフト | 条件 |
|---|---|
| Docker Desktop | 設定の「Use containerd for pulling and storing images」を**オフ**にする（A-4 (b) 参照） |
| Node.js | 24 |
| Git | 任意の最新版 |

## A-2. 初回セットアップ

```bash
npm ci
npx playwright install chromium
npm run env:start          # http://localhost:8888 が立ち上がる
npm run wp -- spc seed     # 仮データ（事例・料金・FAQ・職人）を投入。何度実行しても重複しない
```

- 管理画面は `http://localhost:8888/wp-admin/`（wp-env の既定は `admin` / `password`）。ローカル専用です。
- `wp spc seed` は本番（`WP_ENVIRONMENT_TYPE=production`）では実行できません。

## A-3. テストの実行

```bash
npm run test:php   # spc-core の PHPUnit（wp-env の tests-cli 内で実行）
npm run test:e2e   # Playwright（Chromium）
```

- `test:e2e` は `workers: 1`（直列実行）です。テストが1つの WordPress（設定・投稿）を共有し、一部のテストが設定を書き換えるため、並列にすると互いに干渉します。変更しないでください。
- 単一のテストだけ動かす例：`npm run test:php -- --filter Security`

## A-4. Windows でのトラブル対処

### (a) wp-env が「ネットワークに接続できない」と判定する

Node の DNS が `127.0.0.1` を向いてしまう端末（VPN ソフトなどの影響）で起きます。wp-env が最新の WordPress バージョンを取得できず失敗します。

`~/.wp-env/<ハッシュ>/wp-env-cache.json` を次の内容で作成してください（`<ハッシュ>` は `~/.wp-env/` 直下にあるプロジェクト用フォルダ名）。

```json
{"latestWordPressVersion":"7.1.3"}
```

wp-env がテスト用ライブラリ（WordPress PHPUnit）を取得できない場合は、手動で用意します。

1. `wordpress-develop` のタグ 7.1.3 から `tests/phpunit` だけをスパースクローンする（`git clone --filter=blob:none --sparse` の後に `git sparse-checkout set tests/phpunit`、タグ 7.1.3 をチェックアウト）。
2. 取得した `tests/phpunit` の中身を `~/.wp-env/<ハッシュ>/tests-WordPress-PHPUnit` に置く。

注意：`wp-env destroy` を実行すると、上記のキャッシュファイルとテスト用ライブラリは消えます。再度同じ手順が必要です。通常の作業で `destroy` は使わないでください（`env:stop` で止めるだけにします）。

### (b) Docker のイメージ展開でファイルが壊れる

Docker Desktop の設定 > General > **「Use containerd for pulling and storing images」をオフ**にして、Docker Desktop を再起動します。その後、イメージを取得し直してください。

### (c) メモリ不足でテストが不安定

PHP・E2E のテストが途中で落ちる、極端に遅い場合は、まず PC を再起動します。E2E は `workers: 1` のまま実行します。1回のタイムアウトはバグと決めつけず、同じテストを単独でもう一度実行して確認してください。

## A-5. 本番 `wp-config.php` の設定

```php
define( 'WP_ENVIRONMENT_TYPE', 'production' ); // 仮データの公開停止・非表示が有効になる
define( 'DISALLOW_FILE_EDIT', true );          // 管理画面からのテーマ・プラグイン編集を禁止
define( 'FORCE_SSL_ADMIN', true );             // 管理画面・ログインを常時 HTTPS に
```

- `DISALLOW_FILE_MODS`（管理画面からのプラグイン・テーマの追加／更新を禁止）は、より堅くなりますが、**管理画面からの更新もできなくなります**。採用するかは、ホスティングの運用（自動更新の有無）と合わせて、依頼元・保守担当で決めてください。TODO(仮)
- 本番では `WP_ENVIRONMENT_TYPE=production` が必須です。未設定のままだと、仮データがそのまま公開されます。

### spc-core のセキュリティ設定（`includes/security.php`、導入済み）

- XML-RPC を無効化し、`X-Pingback` ヘッダと RSD リンクを出さない
- 未ログインの REST `/wp/v2/users`（一覧・個別）は 401（他のREST経路とログイン済みの利用には影響しない）
- `?author=N` と投稿者アーカイブは、トップへ 301 で戻す
- `<meta name="generator">`（WordPress のバージョン）を出力しない

## A-6. デプロイ時に除外するもの

- `node_modules/`
- `tests/`（Playwright）
- `.wp-env.json`
- `docs/`
- `.superpowers/`

## A-9. 計測

- `landing_view`（トップ/LP表示時）と `line_click`（`cta_location` = header / fv / steps / cases / final / sticky / qr_modal）は、テーマが `dataLayer` に push します。

## A-10. 公開前の手順

**`wp spc launch-check` が通らない間は、公開してはいけません。**

1. **仮データの差し替え**：仮の事例・料金・職人・FAQ、LINE URL、ブランド名、GTM ID を本物に差し替える（Part B 参照）。
2. **公開前チェック**
   ```bash
   wp spc launch-check
   ```
   残っている項目の一覧が出て終了コード1になる場合は、直して再実行します。**「公開前チェックに合格しました。」と表示されるまで**繰り返します。管理画面のサイトヘルス、管理バーの「仮データ N件」でも確認できます。
3. **GTM / GA4 の公開**：GTM コンテナで GA4 タグ・トリガー（`landing_view` / `line_click`）を設定し、プレビューで動作を確認してから公開する。
4. **noindex と Basic 認証を外す**：管理画面の「設定 > 表示設定」の「検索エンジンでの表示」（検索エンジンがサイトをインデックスしないようにする）のチェックを外し、サーバー側の Basic 認証も解除する。
5. **Search Console 登録**：プロパティを追加し、サイトマップ（`/wp-sitemap.xml`）を送信する。

# Part B　依頼元（管理画面で更新する方）向け

管理画面（`https://サイトのURL/wp-admin/`）にログインして操作します。画面の左側にメニューが並んでいます。わからないときは、保存する前にいったん手を止めて、保守担当へご連絡ください。

## B-1. ブランド設定の変え方

1. 左のメニューから **「設定」→「ブランド設定」** を開きます。
2. 次の項目を入力します。

| 項目 | 入れるもの |
|---|---|
| ブランド名 | 屋号。決まるまでは「（仮）ブランド名」のままにします |
| LINE追加URL | LINE公式アカウントの友だち追加URL（`https://lin.ee/…` など）。サイトの「写真を送って無料相談」ボタンすべてに反映されます |
| LINE QRコード画像 | パソコンで見た方向けのQRコード。「画像を選択」で、LINE公式アカウントの管理画面から保存した画像を選びます |
| GTMコンテナID | `GTM-` から始まる文字列。計測用です。保守担当から教わった値を入れます |
| FVキャッチの組み方（スマホ） | トップの大きな見出しを、スマホで「縦書き」にするか「横書き」にするか。読みにくいと感じたら「横書き」にします |
| 一次返信の目安 | 相談への最初の返信の目安（例：営業時間内24時間以内）。実際に守れる内容を書いてください |

3. 一番下の **「変更を保存」** を押します。

LINE追加URLは、決められた形式以外を入れると仮のURLに戻ります。保存後はサイトのボタンを押して、LINEの画面が開くか確認してください。

## B-2. 施工事例を追加する

1. 左のメニュー **「施工事例」→「新規追加」**（画面上は「施工事例を追加」）を開きます。
2. タイトル（例：ウールコートの赤ワインのシミ）と、受付番号・品目・素材・シミの種類・他店での処置・施工内容・仕上がり・作業日数などを入力します。
3. Before画像（施工前）とAfter画像（施工後）を選びます。
4. 「掲載許諾ID」に、お客様から掲載の許可をいただいた記録の番号を入れます（サイトには表示されません）。
5. 「公開」を押します。

守ること：

- **掲載の許可をいただいていないお客様の写真は、絶対に載せません。** 許諾IDが入れられないものは公開しないでください。
- **写真は加工しません。** 同じ角度・同じ明るさで撮り、シミを消す加工や色味の補正はしないでください。
- **仕上がりは正直に書きます。** 「完全には落ちなかった」「薄くなった」など、結果をそのまま書きます。
- 写真に写り込んだブランドのロゴは、ぼかすか、写らないように撮ります。
- お客様のお名前・住所など、個人が特定できる情報は書きません。
- 口コミやお客様の声を、実在しないのに作って載せることは絶対にしません。

## B-3. 料金を更新する

1. 左のメニュー **「料金」** を開き、直したい行をクリックします（新しく足すときは「料金を追加」）。
2. 「区分」で、料金表のどのグループに入れるかを選びます。
3. 「目安金額（円）」には **数字だけ** を入力します（例：15000）。「円」「カンマ」「〜」は入れません。
   - **0 を入れると、サイトには「お見積り」と表示されます。**
4. 「『〜』を付ける」にチェックすると「15,000円〜」の表示になります。
5. 「補足」に、金額の横の一言（例：税込、状態により変動）を入れます。
6. 「更新」を押します。並び順を変えるときは、右側の「順序」の数字を小さいほど上になるよう変えます。

## B-4. よくある質問を更新する

1. 左のメニュー **「よくある質問」** を開きます（追加は「質問を追加」）。
2. タイトル欄に質問文、本文欄に回答を書きます。
3. 「分類」で、「よくある質問」ページのどの見出しの下に並べるかを選びます。
4. 「トップに表示」にチェックすると、トップページにも表示されます。**トップに出るのは最大5件**です。6件以上チェックしても表示されるのは5件までなので、入れ替えたいときは、先に他の質問のチェックを外してください。

## B-5. 職人を更新する

1. 左のメニュー **「職人」** を開きます（追加は「職人を追加」）。
2. タイトル欄にお名前、「肩書き」「紹介文」を入力します。
3. 右側の **「顔写真」→「顔写真を設定」** で、本人の顔写真を選びます（掲載について本人の同意を得たものだけ）。写真は実際の撮影写真を使い、AI で作った画像は使いません。
4. 「更新」を押します。

## B-6. 「仮データ」のチェックの意味

事例・料金・FAQ・職人の編集画面には「**仮データ（公開前に必ず差し替え）**」というチェックがあります。まだ仮の内容（ダミーの文章・写真・金額）の投稿に付いています。

- 一覧画面の「仮」の列に、印が出ます。
- **本番のサイトでは、仮データの投稿は公開されません。** 公開しようとしても下書きに戻され、メッセージが出ます。
- 本当の内容に書き換えたら、**そのチェックを外して**から公開してください。
- 画面上部の黒いバーの「仮データ ◯件」が、残っている数です。0件になれば公開前の準備はおおむね完了です（最終確認は保守担当が行います）。

## B-7. 書いてはいけない表現

お客様に誤解を与える言い方は、景品表示法の観点からも避けます。次のように言い換えてください。

| 書かない | 言い換え例 |
|---|---|
| 必ず落ちる／100%除去／どんなシミも | 落とせる可能性を職人が確認します |
| 完全に元通り | 目立たない状態を目指します（※結果は状態によります） |
| 業界No.1／日本一／最高級 | 根拠がないものは書かない |
| 他店では無理なシミも | 他店で落ちなかったシミのご相談も承ります |
| 今だけ／残りわずか | 使わない |

そのほか：

- 「！」は使わず、丁寧に静かな文体で書きます。
- 分からないことは分からないと書きます（例：「写真だけでは確定できません。現物を拝見して正式にお見積りします」）。
- 件数・満足度などの実績の数字は、根拠の資料があるものだけ載せます。ないものは載せません。
